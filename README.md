# Incidente-MDR---Detec-o-de-Activity-Scheduler-Malicioso
 Simular a atuação de um Analista Júnior de MDR em um ambiente corporativo. A proposta é receber um alerta bruto de um SIEM, realizar a triagem, enriquecer os dados com threat intelligence, documentar a jornada de investigação e classificar a criticidade para possível escalonamento ao nível 2 .
